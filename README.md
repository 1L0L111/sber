# Атлас трат 2.0 — семь типов российских территорий

Модернизация оригинального интерактивного атласа с сохранением семи типов, карт, траекторий и паспортов МО.

## Посмотреть
Откройте `site/index.html` в браузере. HTML автономен; для GitHub Pages установите **Settings → Pages → Deploy from a branch**, ветка `main`, папка `/site`.

## Исходный код
`src/` — исходные модули автора (кластеризация, построение признаков, графы, ICVI); `app.js`, `style.css`, `body.html` — интерфейс; `build_site.py` — оригинальный сборщик с абсолютными путями автора, требующий адаптации под свою среду. `config/analysis.json` — документированные настройки аналитического слоя.

## Данные
Исходные `consumption`, `connection`, `market_access` предоставляются отдельно в рамках Data→Sense; большой XLSX Росстата также не включён в репозиторий. Для полной пересборки оригинальной кластеризации требуются отсутствующие в данном пакете `t_dict_municipal_districts.xlsx`, подготовленные `out/*.npz`, геометрии и Rosstat parquet. **Не утверждаем, что оригинальный пайплайн воспроизводим без этих зависимостей.** Автономный опубликованный сайт работает без них.

## Население
Новый XLSX — региональные социально-экономические данные Росстата, не муниципальный справочник численности. Поэтому численность МО и population-weighted типы из него не выводятся. Доли по типам относятся к МО, а не к жителям.

## Аналитика
`results/` — предварительные проверки сетевых сигналов и моделей прогнозирования; см. `docs/methodology_ru.md`. Они не являются доказательством причинного распространения. Не путать показатели дополнительного PULSE-анализа с оригинальной семитипной кластеризацией.
