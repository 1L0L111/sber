# Атлас трат 2.0 — семь типов российских территорий

**Интерактивный исследовательский проект на основе данных СберИндекса за 2023–2024 годы.**

Проект исследует различия в структуре и динамике потребительских расходов российских муниципальных территорий. Он развивает оригинальный интерактивный атлас, сохраняя семь типов территорий, карты, траектории и паспорта муниципальных образований (МО).

## Что показывает атлас

- Семь типов муниципальных территорий по характеристикам потребительских расходов.
- Географическое распределение типов и интерактивную карту.
- Динамику расходов и структуру потребления.
- Паспорта отдельных муниципальных образований.
- Дополнительный исследовательский анализ структурных изменений и транспортных связей.

## Данные

Основной период исследования — январь 2023 — декабрь 2024 года.

Используются данные `consumption`, `connection`, `market_access` из набора Data→Sense и дополнительные социально-экономические показатели Росстата.

Исходные наборы данных предоставляются отдельно и не включены в данный репозиторий.

## Методология и воспроизводимость

Исходный атлас использует построение признаков, кластеризацию и анализ динамики потребления. Дополнительный аналитический слой исследует устойчивые структурные изменения и их связь с транспортной доступностью соседних территорий.

Для полной пересборки оригинальной кластеризации необходимы дополнительные зависимости и подготовленные данные: `t_dict_municipal_districts.xlsx`, `out/*.npz`, геометрии и Rosstat parquet.

Оригинальный `build_site.py` содержит абсолютные пути автора и требует адаптации. Поэтому **полная воспроизводимость исходного аналитического пайплайна без дополнительных данных не заявляется**. Опубликованный автономный сайт работает без этих зависимостей.

## Ограничения исследования

Региональные данные Росстата не используются как муниципальная численность населения. Доли семи типов характеризуют количество муниципальных образований, а не долю населения России.

Дополнительные результаты анализа транспортных связей носят исследовательский характер и не доказывают причинное распространение изменений между территориями.

Предварительная оценка прогнозных моделей содержит ограничение, связанное с использованием будущих наблюдений при подтверждении структурных изменений. Такие показатели не следует интерпретировать как качество прогноза в реальном времени.

Подробности приведены в [методологическом отчёте](docs/methodology_ru.md).
