# Методологический отчёт — Атлас 2.0

## 1. Постановка
Исходный атлас выделяет семь типов муниципальных территорий по динамике безналичных расходов. Модернизация сохраняет оригинальную типологию, визуальный язык и интерактивную географию, добавляя анализ неоднозначности типов и дополнительный независимый эксперимент PULSE.

## 2. Данные и единицы наблюдения
В исходном наборе потребления 303 126 строк за январь 2023 — декабрь 2024; 2 190 территорий, 2 016 с полным 24-месячным рядом. Есть пять предметных категорий и «Все категории». Категории не исчерпывают сумму «Все категории». Дополнительно есть market_access и 5 942 364 пар транспортных расстояний.

В загруженном файле `data_01_socio_economic_102_v20260313.xlsx` есть региональные социально-экономические показатели Росстата: столбцы `object_name`, `object_level`, `object_oktmo`, `year`, `indicator_value`, `indicator_unit`. Проверенный пример — показатель `Y477110461` «Численность населения» на уровне **Регион**, единица — тысячи человек. Этот файл не является валидированным муниципальным регистром населения, и подменять им численность МО нельзя. Все доли типов — по количеству МО, а не по численности жителей. Для population-weighted результата нужен отдельный муниципальный источник и проверенная стыковка по ОКТМО/границам.

## 3. Оригинальная кластеризация
`src/features.py`, `src/networks.py`, `src/clustering.py`, `src/icvi.py`, `src/run_clusters.py` — оригинальный код из `code.zip`. Для точной пересборки необходимы дополнительные подготовленные массивы и справочник МО, на которые ссылается исходный `src/build_dataset.py`. Без них нельзя честно заявлять полную воспроизводимость исходных семи типов.

## 4. Дополнительное определение структурного сдвига
Для каждого МО и месяца вычисляются доли пяти категорий в общих расходах. Из долей вычитается медиана по всем МО в этом месяце. Локальная сила изменения — евклидова норма разности между текущим вектором и средним за предыдущие три месяца. Кандидат: верхний дециль по месяцу. Устойчивое событие: сила изменения в следующем месяце не ниже 60-го процентиля. Важно: для ретроспективной маркировки устойчивости используется следующий месяц, поэтому эта метка недоступна в момент самого сдвига.

## 5. Пространственная ассоциация
Для каждого МО определяются k ближайших соседей по автомобильным расстояниям. При k=5 условный риск устойчивого события — 13,49% после события у соседа против 5,25% без него, RR=2,57. При k=1/3/10/20 RR ≈ 2,95/2,51/2,52/2,62. Placebo переставляет сетевую экспозицию внутри месяца. Это свидетельствует об ассоциации, но не доказывает причинное влияние: возможны общие региональные факторы, пространственная автокорреляция и селекция соседей.

## 6. Прогноз
Цель: устойчивое событие в t+1. Модель: логистическая регрессия с признаками собственной истории, структуры расходов и market_access; экспериментальная версия добавляет долю ближайших соседей с текущим устойчивым событием. Expanding-window backtest, PR-AUC и ROC-AUC. History baseline: PR-AUC 0,2556, ROC-AUC 0,8239, Brier 0,1599. Сеть: PR-AUC 0,2632, ROC-AUC 0,8299, Brier 0,1559. Прирост PR-AUC ≈ 3%.

**Критическое ограничение:** сетевой признак «устойчивое событие в t» использует подтверждение события в t+1. Это утечка будущей информации в реальном времени. Поэтому приведённые результаты — **ретроспективный исследовательский ориентир, не доказательство готовой оперативной системы раннего предупреждения**. Перед конкурсной заявкой необходимо переобучить прогноз на каузально доступном candidate shift в t и повторить temporal backtest. Не следует называть текущие цифры продакшн-качеством прогноза.

## 7. Сравнение методов обнаружения точек изменений
Исходный атлас исследует устойчивость типов и их переходы; PULSE использует robust change score. Формальное сравнение CUSUM, PELT, Bayesian online change-point detection по единой размеченной выборке в переданных артефактах отсутствует. Числа для этих методов не выдумываются. Это обязательная незакрытая часть для полной конкурсной заявки.

## 8. Примеры
В `results/structural_shift_events.csv` содержатся реальные идентификаторы МО, даты и категории-драйверы. Для перевода идентификаторов в названия нужен словарь МО и контроль версии справочника. Региональные статистики не приписываются конкретному МО.

## 9. Архитектура
СберИндекс CSV → контроль полноты → доли категорий → семитипная типология оригинала → структурные изменения → транспортные соседи → ретроспективная валидация → интерактивный атлас → GitHub Pages.
