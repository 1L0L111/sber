Сдвиги: что действительно сравнили

В дополнительном исследовании использован один операционный detector: изменение долей относительно трёхмесячной истории после удаления общероссийского тренда. Сравнение с CUSUM/PELT не выполнено — метрики для них не заявляются.

Реальный пример

Для пяти ближайших дорожных соседей RR устойчивого сдвига составляет 2,57× (13,49% против 5,25%). Проверены k=1, 3, 5, 10, 20; это пространственная ассоциация, а не причинность.

Население: важная граница интерпретации

Загруженный Росстат содержит региональные показатели населения, но не подтверждённые численности всех муниципалитетов. Поэтому доли типов считаются по числу МО. Подмена населения МО региональным значением недопустима.
